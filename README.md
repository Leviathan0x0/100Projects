# 100 Web Projects (HTML, CSS & JS) 🚀

Welcome to my **100 Projects** challenge! This repository is a curated collection of frontend web projects built to master vanilla **HTML5**, **CSS3**, and modern **JavaScript (ES6+)**. 

Each project is designed from scratch with a focus on responsiveness, clean aesthetics, smooth interactions, and solid engineering practices.

- **Layouts**: Flexbox, CSS Grid, Custom properties, responsive designs.
- **Interactions**: Event handling, DOM manipulation, animations (transitions, hover effects).
- **APIs & Data**: Fetching third-party APIs, working with JSON, asynchronous functions.
- **Storage**: LocalStorage for data persistence across page reloads.
